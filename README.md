# ShareIt

ShareIt — это бэкенд-приложение на Java/Spring Boot для краткосрочного шеринга вещей.
Сервис позволяет пользователям делиться своими вещами, бронировать предметы других пользователей, искать доступные вещи и создавать запросы на ещё не добавленные предметы.

## Функциональность

### Основные возможности

- Добавление вещей для шеринга: владелец описывает предмет, его доступность и условия использования.
- Бронирование вещей: пользователи могут отправлять запрос на аренду вещи на выбранный период. 
- Подтверждение или отклонение бронирований владельцем вещи.
- Просмотр информации о собственных вещах и связанных с ними бронированиях (прошлых, текущих, будущих).  
- Поиск вещей по названию и описанию среди только доступных к бронированию предметов.
- Работа с запросами вещей: создание запросов на вещи, которых ещё нет в системе, просмотр своих запросов и ответов на них, предложение вещей в ответ на запросы других пользователей.

## Архитектура проекта

Приложение реализовано как двухмодульный сервис, части которого общаются по REST.

- **shareit-server** — основной сервис, содержащий всю бизнес-логику, работу с базой данных, бронированиями, запросами и вещами. 
- **shareit-gateway** — «фасад»/прокси, принимающий внешние запросы, выполняющий валидацию входных данных и проксирующий их на сервер.

Основные сущности:

- **User** — пользователь сервиса (id, имя/логин, email и т.д.).
- **Item** — вещь, доступная для шеринга (id, название, описание, флаг доступности, владелец, связь с бронированиями и запросами). 
- **Booking** — бронирование вещи (id, временной интервал, статус, ссылка на пользователя и предмет).
- **ItemRequest** — запрос на вещь, которой ещё нет в системе (id, описание, дата создания, список вещей, созданных в ответ).

## Стек технологий

- Java 11+.
- Spring Boot, Spring Web, Spring Data JPA/Hibernate.  
- PostgreSQL в качестве основной СУБД. 
- Maven для сборки.  
- Lombok для сокращения шаблонного кода.
- JUnit, MockMvc для тестирования REST-эндпоинтов и слоёв приложения.  
- Docker и docker-compose для развёртывания
